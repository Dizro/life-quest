# 🎮 LifeQuest

**LifeQuest** — это геймифицированный трекер задач в формате RPG с ИИ-наставником. Рутинные дела превращаются в квесты: за выполнение начисляются опыт, уровни и валюта, а ИИ оценивает сложность задач (Effort Score) для защиты от накруток.

⚠️ **Текущий статус (MVP - Спринт 3):** Готов бэкенд для Release Candidate (MVP). Развернута интеграция ИИ-наставника (YandexGPT) через асинхронную очередь Celery, реализована система стриков, испытаний, дневных ограничений (Агрегация), а также многослойная античит-защита.

![Swagger UI](docs/swagger.png) 

## 🛠 Технологический стек
* **Фреймворк:** FastAPI (Python 3.10+)
* **База данных:** PostgreSQL 15 + SQLAlchemy 2.0 (ORM) + Alembic (Миграции)
* **Асинхронные задачи:** Celery + Redis (Брокер) + Celery Beat (Крон)
* **Нейросеть:** YandexGPT 5 Lite (оценка Effort Score через API)
* **Безопасность:** JWT (Access/Refresh токен), HTTPBearer, Pydantic-валидация

## 🚀 Быстрый старт (Docker)

Для запуска бэкенда локально потребуется только установленный Docker.

**1. Клонировать репозиторий:**
```bash
git clone https://codelab.tpu.ru/egk17/lifequest.git
cd lifequest/lifequest-backend
```

**2. Настроить переменные окружения:**

```bash
cp .env.example .env
```
*(Внимание: Для работы оценки сложности (Effort Score) добавьте в `.env` ключи от Yandex API: `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. Если ключей нет, система будет назначать дефолтный ES=5).*

**3. Поднять контейнеры:**

```bash
docker-compose up -d --build
```
*(В docker-compose.yml уже настроен одновременный старт FastAPI, PostgreSQL, Redis, Celery Worker и Celery Beat).*

**4. Применить миграции и наполнить базу стартовыми данными:**

```bash
docker-compose exec api alembic upgrade head
docker-compose exec api python seed.py
```

**5. Открыть документацию API:**

* Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)
* ReDoc: [http://localhost:8000/redoc](http://localhost:8000/redoc)

## ⚔️ ИИ-Наставник и Геймификация (Спринт 3)

**Многослойный Античит:**
* **Слой 0 (Синтаксис):** Квесты проходят строгую валидацию длины (запрет на спам цифрами, недопустимость пустых слов). А также защита от точных дубликатов задач в сутки.
* **Слой 1 (ИИ-оценка):** Фаррикс (YandexGPT) отсеивает бессмыслицу и присваивает Effort Score (от 0 до 10).
* **Слой 2 (Дневная Агрегация):** Бэкенд контролирует ежедневный потолок извлечения XP (200 + Уровень * 20) и отдельный потолок для привычек (30 XP).
* Адаптивная защита от Replay-атак при завершении.

**Фоновые процессы (Celery Beat):**
* `reset_broken_streaks` — Сбрасывает серии активности, если игрок пропустил день (в 00:05).
* `transition_overdue_tasks_to_trial` — Переводит просроченные задачи в статус «Испытание» (штраф к опыту/золоту, блокировка редактирования условий дедлайна).

## 📡 Информация для Frontend-разработчиков (Работа с API)

API использует JWT-авторизацию.

**Жизненный цикл игрока:**

1. Зарегистрируйте пользователя: `POST /api/v1/users/`. *(Новичок автоматически рождается со стартовым капиталом 50 Gold и баффом х2 на опыт).*
2. Получите токен: `POST /api/v1/auth/login`. *(Если игрок отсутствовал более 7 суток, сработает механика "Воскрешение" — старые испытания уходят в архив, выдается приветственный х2 бафф).*
3. В последующие запросы к API добавляйте HTTP-заголовок: `Authorization: Bearer <ваш_access_token>`.

**Ключевые эндпоинты задач:**
* Создание задачи (`POST /tasks/`) возвращает статус `pending_es`. Подождите 1-3 секунды — Celery асинхронно обновит статус задачи на `active` и запишет Effort Score.
* Завершение (`POST /tasks/{id}/complete`) возвращает итоговую награду, генерирует фразу от Фаррикса и отдает флаг `leveled_up` (Level Up) или `achievement_unlocked` (Ачивка).
* Выкуп просроченной: `POST /tasks/{id}/redeem` — возможность закрыть Испытание за монеты (Лимит 3 раза в день).

```text

├── alembic/        # Файлы миграций базы данных (Alembic)
├── app/
│   ├── api/        # Роуты (эндпоинты) API v1
```
